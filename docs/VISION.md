# CLWA: Shangri-La Vision

> Долгосрочное видение проекта. Не план на завтра — ориентир на горизонте.
> Текущая работа: GDD_DETECTIVE.md (Crime & Justice roguelike).

---

## Что такое CLWA в финальном виде

Живой мир, вдохновлённый Shangri-La Frontier. Сотни NPC, которые помнят, решают, меняют отношения. Десятки локаций с уникальной атмосферой. Несколько игроков, чьи действия влияют на общий мир. Не MMO с kill-10-wolves — а мир, где каждый NPC живёт своей жизнью, и ты выбираешь свою роль через поступки.

---

## Игрок — Странник

Нет классов. Нет профессий. Мир определяет кто ты по твоим действиям.

- Расследуешь → NPC считают тебя детективом
- Торгуешь → ты торговец
- Крадёшь → ты преступник
- Помогаешь → тебя уважают
- Предаёшь → тебе не доверяют

Bilateral design: игрок = Agent. Те же beliefs, relationships, trust, affordances что у NPC. Класс не в коде — класс в восприятии NPC.

**Контекст прибытия:** каждая локация даёт начальный импульс (в Millhaven — анонимная записка → детективная работа, в порту — контракт на охрану → телохранитель). Но это крючок, не ограничение.

---

## Модульный мир

Один движок, разные модули. Каждый модуль добавляет affordances, CG-правила, topic sources — в существующие локации.

| Module | Content | Player Experience |
|--------|---------|-------------------|
| **Crime & Justice** | Кража, убийство, расследование, суд | Детективная работа, соучастие, самосуд |
| **Economy** | Торговля, долги, контрабанда, цены | Торговля, обогащение, банкротство |
| **Politics** | Фракции, законы, коррупция, выборы | Интриги, альянсы, перевороты |
| **Combat** | Оружие, раны, территория, наёмники | Тактический бой, защита, захват |
| **Social** | Браки, семьи, праздники, репутация | Дипломатия, сватовство, скандалы |

Модули пересекаются: убийство торговца (Crime) обваливает цены (Economy) и вызывает политический кризис (Politics).

---

## Мир растёт через обновления

Не процедурная генерация. Каждая локация — handcrafted, с уникальной географией, NPC, «напряжениями». Но NPC-трейты рандомизируются каждый запуск → одна локация, тысячи историй.

**Сейчас:** Millhaven (8 NPC, Crime & Justice)
**Далее:** Портовый город (Economy), Столица (Politics), Горная деревня (Combat)
**Долгосрочно:** 10-20 локаций, связанных дорогами. Репутация переносится.

## Поэтапное наслоение

| Этап | Продукт | Масштаб |
|------|---------|---------|
| **1. Solo Roguelike** | Millhaven detective, 1.5-2h прогон | 1 игрок, 8 NPC, local |
| **2. Coop (2-4)** | Совместное/конкурентное расследование | 2-4 игрока, 15-20 NPC |
| **3. Расширение** | 2-3 локации, Economy + Politics | 2-4 игрока, 30-50 NPC |
| **4. Persistent** | Мир 24/7, SpacetimeDB | 10+ игроков, 50-100 NPC |
| **5. MMO** | Региональные серверы | Десятки игроков, сотни NPC |

Каждый этап — самостоятельный продукт. Можно остановиться на любом.

## Технологический стек на будущее

| Этап | Бэкенд | LLM | Клиент |
|------|--------|-----|--------|
| 1-2 | Bun + WebSocket | Local Qwen 9B (RTX 3080) | Web UI (Canvas2D) |
| 3 | Bun + WS или SpacetimeDB | Local + Hot/Warm/Cold | Web UI |
| 4-5 | SpacetimeDB | Cloud LLM (DeepSeek и т.д.) | Web UI / Godot |

**SpacetimeDB:** вся логика в базе данных. Нет отдельного game server. Клиенты подписаны на таблицы → auto-sync. Проверено на BitCraft MMORPG. Free tier: 3M reducer calls/month.

**Hot/Warm/Cold NPC:**
- Hot (рядом с игроком): полный LLM, память, цели
- Warm (видно из соседней локации): обновление state без LLM
- Cold (далеко): только числа (mood += delta)

## Мультиплеер: ключевые решения (на будущее)

1. **Нет ролевых ограничений.** 10 игроков хотят расследовать одно убийство → 10 расследуют. Конкуренция за trust свидетелей, разные стратегии, конфликт между игроками — всё контент.

2. **NPC масштабируются с игроками.** 7 NPC на 1 игрока. 50 NPC на 10 игроков. Каждый NPC помнит каждого игрока отдельно (per-player trust, beliefs, relationships).

3. **Действия одного → последствия для всех.** Ты раскрыл заговор → весь город узнал. Другой игрок устроил контрабанду → цены для всех изменились.

4. **Закладки на сейчас (для solo):**
   - НЕ добавлять паузу мира (только ускорение) — пауза ломает мультиплеер
   - Тик-система уже real-time (auto-tick) ✓
   - Bilateral design ✓
   - Save: переход на периодический автосейв (не on-SIGINT) к этапу 2

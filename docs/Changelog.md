## [0.18.0] — M7 «Economy & Trade» — 🔨 В РАЗРАБОТКЕ (ветка `feature/economy`, не смержена)

Второй жанр на универсальном движке — доказательство тезиса CLWA «один движок поведенческой физики, контент = модули данных».
Экономика построена почти целиком как контент модуля + 3 новых **универсальных** примитива движка (не crime-, не economy-специфичных).

### Добавлено
- **Примитивы движка (универсальные):**
  - **E1 — дрейф скалярных атрибутов**: атрибут может плавно двигаться к цели (линейно или экспоненциально). Основа для эволюции цен и роста нужд.
  - **E2 — overdraft-перевод**: перевод атрибута может уводить источник в минус до пола (для долгов/кредитов), сохраняя консервацию.
  - **E3 — реестр INTENT_KIND**: намерения игрока в диалоге стали данными модуля (сняли «торговую» утечку из IL-слоя движка).
- **Модуль economy** (весь торговый контент через реестры, движок не знает слова «торговля»):
  - Торговые аффордансы: buy / sell / haggle / produce / hoard / smuggle / lend / collect_debt.
  - Экономическое принятие решений: давление нужды/долга поднимает полезность экономических действий.
  - **Динамические цены**: цена за товар дрейфует к рыночной цели по supply/demand (дефицит → дороже).
  - **Нужды**: голод растёт со временем (дрейф), еда сбрасывает его.
  - **Долг/кредит** на overdraft: выдача займа → запись в реестр долгов → взыскание; дефолт уходит в пол.
  - **Кросс-модульная связь экономика → преступление**: дефолт долга порождает грудж (PERSONAL_GRUDGE), на который реагируют аффордансы преступления (угроза/ссора/убийство). Нулевой общий код между модулями — только через CG-шину.
- Living Millhaven: торговцам (Mark, Hilda, Bess) проставлены capability `isMerchant` / `canProduce`.

### Осталось до релиза (P6 + финал)
- Полировка фронта: скрыть золото торговца от игрока, панель инвентаря игрока, стоп протечке NPC↔NPC реплик в чат, магазин игрока на динамическую цену.
- Рынки-как-venues, контрабанда/мошеннические кольца, эмиссия SHORTAGE из тика цен, доп. кросс-модульные CG-правила.
- Финальный аудит (clwa-auditor) всего диффа M7, обновление ROADMAP/ARCHITECTURE, мерж в master.

## [0.17.0] — M6 «NPC Brain» — 2026-05-30

Максимизация качества отыгрыша: слоистые промпты, инженерия контекста, маршрутизация моделей.

### Добавлено
- **Слоистый промпт**: L1 scaffold (правила) / L2 persona (личность) / L3 volatile (текущее состояние) — собирается в движке.
- **Маршрутизация моделей per-task**: диалог игрока + вердикт → claude-code/Sonnet; volition / npc-dialogue / reflection / il / embeddings → LM Studio/Qwen.
- **Русская локализация** in-voice few-shot для 8 NPC Millhaven.
- **Chat-staleness TTL в реальном времени**: разговор «протухает» по таймеру (по умолчанию 5 мин, `WorldConfig.chatStaleMs`) вместо обнуления при переключении NPC.
- Контролы в World Editor: scaffold-промпт, язык, chat-TTL, few-shot.

### Изменено / Исправлено
- Анти-повторы в NPC-диалоге; вердикт «причина → решение» + калибровка severity; санитайз вывода рефлексии.
- IL few-shot против over-extraction + fallback-маршрут; окно истории NPC↔NPC (3 строки) для follow-up.
- Единый ранкинг убеждений + recency-cue + per-event фразировка; восстановление recall памяти через нормализованный score.

## [0.16.0] — M5 «Engine Generalization» — 2026-05-29

Превращение crime-движка в **жанро-нейтральный** + универсальные примитивы состояния. Поведение crime-игры — регрессионный оракул (идентично до/после).

### Добавлено (Phase B — универсальные примитивы)
- **B1 — скалярные атрибуты**: универсальный квантованный стейт (база + диапазон + таймед-модификаторы). Одна основа под золото / HP / standing / нужды.
- **B2 — инвентарь / item-instance / атомарный перевод**: консервируемая стоимость и владение (делает кражу/торговлю реальным перемещением стейта).
- **B3 — отношения + членство во фракциях**: коллективные акторы и богаче социальный стейт.
- **Living Millhaven demo**: золото / инвентарь / фракции / standing видимы и играбельны — **без единой правки движка**.

### Изменено (Phase A — нейтрализация движка)
- Слив всей crime-специфики из движка в модуль через реестры:
  - источник `GOSSIP` для разговорной передачи убеждений (вместо хардкода `'rumor'`);
  - `registerRoleDirectiveBuilder` (ролевая проза) + `registerBeliefPhrasing` (NL-фразировка убеждений) — движок даёт нейтральный fallback;
  - secret-directives стал чистым агрегатором; requirements резолвятся через реестр (без crime-полей в интерфейсе);
  - флаги способностей `AgentProfile` → открытая `capabilities`-карта (единый источник — CG-оп `has_capability`);
  - `EmotionalPressure.type` — строка из реестра, а не закрытый union; зачищены pre-seeded crime-дефолты;
  - **`CrimeScene` → `SceneResidue`** (жанро-нейтральный примитив; sceneType — свободная строка).
- Замер само-достаточности движка: 7/10 → 8.5/10, утечки crime-вокабуляра слиты.

### Исправлено
- Pre-merge аудит: баг консервации стоимости при переводе + согласованность отношений.

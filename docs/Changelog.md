## [Worldbuilding] — мир «Отрицание / Relict» (брейншторм-фаза, без версии)

Заложена «библия» следующего игрового мира — камерного диалогового сеттинга, где редкие
люди (**Relict**) отрицают один закон реальности. Это **дизайн-доки** (`docs/world/`), не
код движка; отдельный трек развития со своим планом (`docs/world/_Universe-Roadmap.md`).

### Добавлено
- **Концепт и типология:** классы Recluse / Vector (тип = порванная связь → locus),
  самоназвание Relict; 3 оси class/form/scaling + сцепка-ограничение; вызревание +
  «окно лечения»; редкость = конъюнкция 4 ворот; уникальность Отрицаний. Designation
  `De-`+латынь, каталог-номер `R-[R|V]-NN`.
- **Каст (6 досье + игрок):** Mara / Orin / Wren (Vector), Halden / Senna (Recluse),
  обслуга Brevik и Illa; игрок — работник → Relict с кристаллизацией по ходу прогона.
- **Мир:** Объект (фарма-фронт + невидимая верхушка, сеть, приём «известность = захват»),
  планировка-как-протокол, напряжения T-01…08, лор / сеттинг / история / власть.
  Люди — обычные, но с «чувством закона» (соматический субстрат, обосновывает Негацию);
  своё лёгкое летоисчисление.
- **Измерение:** прибор DEROGAT (индекс отклонения закона); «терапия» как belief-заглушка.
- **Метасюжет:** держится в отдельном спойлерном файле (writer-only).
- **Дизайн и каркас:** core loop (3 петли), лестница модулей (Containment / Operations /
  Research), реролл; стартовый канон + страж масштаба (`_Canon-Core`); методичка
  ворлдбилдинга (`GUIDE`).
- Сознательная отстройка от Undead Unluck и Arknights.
- **Культура крыла (слой 2.2):** ровность=анестезия, имя↔номер, этикет ладони, сленг
  (4-й регистр), ритуалы, фолк-эсхатология «смерть = чистое лечение».
- **Adversarial diamond-пасс** (28 агентов, 7 линз → верификация → синтез): вердикт
  near-diamond, отчёт в `docs/workflow/negation-lore-diamond-pass/`.
- **Verify-пасс → вердикт DIAMOND:** фаза подтверждена (13 правок применены, 0 регрессий);
  отчёт в `docs/workflow/negation-lore-verify-pass/`.
- **Таксономия + каталог (1.4):** граница пространства Отрицаний (страты ткани × магнитуда),
  каталог-как-артефакт (кривой гроссбух: мис-файлы / отвергнутые прото-классы / R-0);
  **«кладбище закрытых номеров»** = банк для расширения каста/реролла; примеры-записи
  DEMEMOR / DEPONDUS / DEVINCIRE.
- **Сеть Объектов (2.3):** наш Объект = **«Отстойник»** (осадок сети — куда оседает
  нерентабельный остаток); 4 канала входа в кадр (главный — **transfer = движок каста/реролла**);
  силуэты-слухи Верх (ским полезных) / Сайт (дред).
- **Метасюжет / раскрытие (3.1, проработан целиком):** reveal-каскад × механика Research
  (6 ступеней × глагол × окно прогона × спойлер-граница); буквальность генезиса; судьба
  DEXISTERE = намеренно вечный открытый ужас; адресная карта зацепок (правило-3-улик);
  игрок как двойной канал раскрытий (работник / изнутри).
- **Структура двух актов:** Работник (~35-40%) → перелом → Узник (~60-65%); один Объект/каст/
  система, меняется только доступ/роль; **браслет DEROGAT** — символ-мост (надевал на других →
  надели на тебя).
- **Досье игрока (PL-1):** заданный персонаж (модель Disco — не игрок генерит) + рероллящийся
  темперамент; Отрицание формируется по ходу, каталог-номер заводится при кристаллизации.
- **Аудитор (AU-1):** безличная функция-**клапан давления** (полу-видимый контакт верхушки;
  не персонаж, не bilateral).
- **Прокачанный роадмап:** ~62 конкретных пункта (приоритеты / зависимости / целевые файлы) +
  секция Engine-bridge; собран многоагентным воркфлоу (отчёт в `docs/workflow/roadmap-upgrade-negation-world/`).

### Изменено
- Старый мир Millhaven заархивирован → `docs/_archive/millhaven-world/`.
- `CLAUDE.md`: модуль economy внесён в карту архитектуры (фикс дрифта).
- Orin канонизирован как редкий **гибрид формы** (ambient+directed); схема Negation
  выровнена genre-neutral (класс деривируется из `effectLocus`, не хранится строкой —
  INV-14); калибровка цен/ярлыков по касту после diamond-пасса.
- **Designation R-0: DEESSE → DEXISTERE** (`De-`+*existere* «не-существовать», форма `-ere`
  как DELATERE) — переименовано по всему волту + этимология.
- Термин «крошки» → **«зацепки»** (по всему волту).
- **Зафиксирован якорь-видение:** жанр = **immersive sim** (антагонист структурный — система +
  сам игрок, не босс; конфликт решается системно через аффордансы, не боёвкой) — `CONCEPT §1`.

## [Запланировано] — спеки готовы, реализация впереди

- **M8 «Personality Plasticity»** (proposed `v0.19.0`) — слой пластичности личности: прожитый опыт (включая применение способностей) необратимо сдвигает базовую личность. Единая физика деформации — упругое настроение / пластическая личность — поверх существующего примитива скалярных атрибутов + открытый реестр осей (OCEAN+H засеяны движком, модули добавляют свои). Спека готова (аудит + cold-start fidelity), реализация впереди.
- **M9 «Affordance-Space Modifier»** (proposed `v0.20.0`) — универсальный примитив «агент или зона меняет множество возможных действий цели» (на себя / на другого / на зону), сила масштабируется от веры и отношений; шов «применение способности → цена пластичности». Спека готова, реализация — после M8.

> Обе спеки genre-neutral: движок не знает мира «Отрицание» — концепт лишь ориентир ширины. Детали: `docs/specs/SPEC-personality-plasticity.md`, `docs/specs/SPEC-affordance-modifier.md`.

## [0.18.0] — M7 «Economy & Trade» — 2026-06-01 (отгружен, смержен в master)

Второй жанр на универсальном движке — доказательство тезиса CLWA «один движок поведенческой физики, контент = модули данных».
Экономика построена почти целиком как контент модуля + 3 новых **универсальных** примитива движка (не crime-, не economy-специфичных).

### Добавлено
- **Примитивы движка (универсальные):**
  - **E1 — дрейф скалярных атрибутов**: атрибут может плавно двигаться к цели (линейно или экспоненциально). Основа для эволюции цен и роста нужд.
  - **E2 — overdraft-перевод**: перевод атрибута может уводить источник в минус до пола (для долгов/кредитов), сохраняя консервацию.
  - **E3 — реестр INTENT_KIND**: намерения игрока в диалоге стали данными модуля (сняли «торговую» утечку из IL-слоя движка).
- **Модуль economy** (весь торговый контент через реестры, движок не знает слова «торговля»):
  - Торговые аффордансы: buy / sell / haggle / produce / hoard / smuggle / lend / collect_debt.
  - Экономическое принятие решений: давление нужды/долга поднимает полезность экономических действий.
  - **Динамические цены**: цена за товар дрейфует к рыночной цели по supply/demand (дефицит → дороже).
  - **Нужды**: голод растёт со временем (дрейф), еда сбрасывает его.
  - **Долг/кредит** на overdraft: выдача займа → запись в реестр долгов → взыскание; дефолт уходит в пол.
  - **Кросс-модульная связь экономика → преступление**: дефолт долга порождает грудж (PERSONAL_GRUDGE), на который реагируют аффордансы преступления (угроза/ссора/убийство). Нулевой общий код между модулями — только через CG-шину.
- Living Millhaven: торговцам (Mark, Hilda, Bess) проставлены capability `isMerchant` / `canProduce`.

### P6 — полировка, обогащение, завершение
- **Фронт (UX):** золото и инвентарь NPC скрыты от игрока; постоянная панель инвентаря игрока в HUD; реплики NPC↔NPC больше не протекают в чат игрока; магазин игрока заряжает динамическую цену (как и NPC-сделки).
- **Мошенничество и контрабанда:** новый аффорданс `defraud` — торговец обманывает покупателя (событие FRAUD, разносится сплетнями); кольцо контрабандистов — `smuggle` вводит NPC во фракцию `smugglers`.
- **Дефицит → давление:** тик цен эмитит событие SHORTAGE → кросс-модульное правило `SHORTAGE → DEBT_PRESSURE` (нехватка обостряет нужду и подталкивает к торговле/контрабанде).
- **Завершение:** финальный аудит (clwa-auditor — 0 must-fix, движок остаётся genre-neutral) + живой прогон подтвердил, что новые системы реально выбираются и исполняются NPC; **смержено в master**. 303 теста зелёные.

### Изменено (инструменты)
- **docs-reader** (`bun docs`) всегда отдаёт свежие данные с диска (no-store) — браузер больше не показывает залипший кеш.

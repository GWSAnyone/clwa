# Ted-Mark Gambling Debt

## Initial Conditions
- [[Ted]] owes [[Mark]] money from gambling debts
- Ted → Mark: sentiment -0.15, trust 0.3
- Mark → Ted: sentiment -0.1, trust 0.2
- Ted's secret: watering down ale to cover debts

## Why It Matters
- Creates additional pressure on Ted (already struggling with honesty)
- Mark can use the debt as leverage
- If player investigates Ted's watered ale, it connects to this tension
- Ted might side with Mark out of debt obligation, or resent him

## Possible Outcomes
- Mark pressures Ted for repayment → Ted more desperate → worse ale → caught
- Player discovers watered ale → Ted confesses about debts → leads to Mark
- Ted confesses to priest → Aldric mediates
- Ignored: simmers as background tension

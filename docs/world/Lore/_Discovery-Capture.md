> [!summary] TL;DR
> Реликта выдаёт **чужое тело**: рядом «чувство закона» фонит, популяция = сеть сенсоров,
> донос ощущается праведным (моральная анестезия телесна). Аппарат подтверждает, лепит
> класс по симптому (**исток мис-файла**), принимает «на лечение». Несущая проблема:
> Отрицание **всегда-вкл** → сотрудничество снимает сопротивление, но **не опасность**.
> Две оси (воля ↔ полевая угроза) — разные инструменты: пространство, седатив-заглушка,
> изоляц-риги, бесконтакт, и **Relict-охотники** (контракт) для неподступных. Каждое
> Отрицание **саботирует свой инструмент захвата** → протокол под каждое.

# Обнаружение → захват (дорога в Объект)

> Слой 1.3 (`_Universe-Roadmap`). Операционная логистика: как находят, доставляют и
> содержат при захвате — для всех случаев (доброволец / содействующий-но-опасный /
> агрессивный / неподступный). На «чувстве закона» (§2) + «известность = захват» (§4)
> + фарма-фронт. Фаза брейншторма.

## Конвейер (кратко — детали в `_Setting`)
1. **Манифестация + соматика:** закон фонит, рядом **чуют неправильность**; копятся
   аномалии. Спрятаться почти нельзя — выдают окружающие.
2. **Донос:** ощущается праведным/облегчающим (соц. закон «сломанных забирают» — телесен).
   Звонят на «линию помощи» фарма-компании.
3. **Полевое подтверждение + классификация:** интейк-агенты, портативный DEROGAT-зонд,
   инференция закона по симптому → класс Recluse/Vector. **Однократно, под давлением →
   исток летального мис-файла (#3, Senna).**
4. **Приём «на лечение»** → дорога в Объект → Intake Hall (S-01) → DEROGAT на запястье → каталог.

## Несущая проблема: Отрицание — ТРАНСПОРТНАЯ опасность
Дар не «выключить» сотрудничеством: ambient (Vector) и self (Recluse) — **всегда-вкл,
непроизвольны** (CONCEPT §2). Значит **две независимые оси**, и их закрывают раздельно:

| Ось | Что значит | Чем закрывают |
|-----|-----------|---------------|
| **Воля** (содействует ↔ агрессивен) | сопротивляется ли человек | переговоры / felt-rightness / принуждение |
| **Полевая угроза** (всегда-вкл) | дар опасен независимо от воли | пространство · седатив-заглушка · риги · бесконтакт · Relict-охотник |

**Вывод:** даже полностью содействующий реликт — опасен (поле не молчит). Самый частый
случай — **содействующий-но-опасный**, и вся логистика заточена под него (будничный
медицинский вывоз человека, чьё присутствие — хазард).

## Инструментарий аппарата (и его ПРЕДЕЛЫ — 2-й закон)
- **Пространственный контроль** (главный для ambient): расчищенный коридор, буфер, вывоз
  без живого эскорта в радиусе, маршрут по низкой плотности. *Предел:* directed это не гасит.
- **Седатив-заглушка — препарат «Quies»** (belief-scaling; `_Setting` / §6.6 / спойлер):
  подавить веру/сознание → индекс DEROGAT падает → перевозить безопаснее. *Предел:* это
  «фальш-лечение» (рецидив, зависимость); для self/ambient **снижает, не снимает**; не
  предотвращает **прорыв на шоке**; нанести надо, ещё не входя в поле (ранний дротик /
  удар по вере без контакта); на DEFINIS-носителях (Mara/Halden) химия стопорит — не берёт.
- **Изоляц-риги** под класс: одиночка (Senna), герметик от утечки (Orin), и т.д. *Предел:*
  у каждого Отрицания свой обход (ниже).
- **Бесконтакт / дистанционка:** хэндлеры не входят в поле; удалённое ведение, авто-везти,
  или содействующий **идёт сам** через расчищенное. *Предел:* нужен хоть какой-то контроль.
- **Relict-охотники (контракт, Operations):** к неподступному полю, где человек не
  выживает/не функционирует, шлют **другого реликта** (содержимого, по контракту — «охота
  на своих»): он выдерживает/контрит то, что людей валит. **Капча опасных = вход в
  Operations-петлю** (сшивка с контрактами). *Предел:* дорого, морально тяжело, риск.

## По случаям (протоколы)
- **Доброволец / содействующий пришёл сам:** приём как «пациент». Лёгкая заглушка для
  транспорта, буферный вывоз. Принуждать не нужно — самое жуткое и частое.
- **Сообщили, не пришёл (содействующий):** агенты «приглашают»/сопровождают (вид скорой);
  заглушка + расчищенный транспорт. Община **помогает** (felt-rightness).
- **Содействующий-но-опасный (воля «да», поле «нет»):** воля закрывает сопротивление
  (идёт сам, не дерётся) + полевые-контролы закрывают хазард (заглушка, коридор, бесконтакт).
  Базовый режим аппарата.
- **Опасный / агрессивный (воля «нет» + дар-оружие):** ранговая седация/удар-по-вере без
  контакта; герметичная мобильная келья + дистанционка; при неподступности — **Relict-
  охотник**. Если и так нельзя — см. ниже.
- **Неподступный (поле не даёт приблизиться никому):** (а) **запечатать место** (временный
  Объект на точке, не везти); (б) **летальная сила** — смерть гасит Отрицание (правило
  смерти, §2) — крайнее, теряет Operations-ценность; (в) при DEESSE-масштабе — неуправляемо,
  негатив-протокол/отступление (спойлер).

## Каждое Отрицание САБОТИРУЕТ свой захват (протокол под каждое)
| Реликт | Что ломает захват | Обход |
|--------|-------------------|-------|
| **Mara** (DEFINIS, чужое) | седатив-процесс в теле хэндлера/субъекта **не завершается** (стопор); эскорт в радиусе не ранить/не убить, но и не вылечить | удар по вере (не химия); ранняя доза до входа в радиус; бесконтакт |
| **Orin** (DELATERE) | у команды **всплывают свои тайны/страхи** → деморализация, компромат на самих хэндлеров | люди «без скелетов», маски/удалёнка, заглушка |
| **Wren** (DESONUS) | команды/тревога/координация **не доносятся**; с ней не договориться голосом | жесты/письмо/заранее-сигналы; заглушка |
| **Halden** (DEFINIS, своё) | **нельзя убить/вырубить** (процесс в нём не завершается) — сила и наркоз бессильны | только содействие/пространство — но он пассивен, хочет уйти → охотно идёт (ирония: «несокрушимый» = безопаснейший) |
| **Senna** (DESEPARE, своё) | хэндлеры рядом **теряют границу/решимость** (растворяются в ней) | краткий контакт, ротация, без привязки, дистанционка; NB изоляция её стирает (мис-файл) |

## Инверсия для игрока
Игрока **не везут** — он кристаллизуется **внутри**. «Обнаружение» оборачивается внутрь:
коллеги **чуют, как он идёт вразнос**, инструменты ловят раньше слов. Он минует дорогу в
Объект, но проходит обнаружение в полной мере — и сразу попадает под те же протоколы.

## Цена (триаж Illa)
Захват — со счётом: потерянные хэндлеры, убитые при неподступности реликты, мис-файлы
с приёма. Аппарат **принимает потери** (холодный триаж — домен S-02). Предпочитают захват
(Operations-ценность), но списывают, когда дешевле списать.

## Заложенные «а что если» (competence-чек GUIDE)
- *Как приблизиться к always-on полю?* → ранняя седация/удар-по-вере без контакта, бесконтакт, Relict-охотник.
- *Почему опасные не сбегают/не побеждают?* → инструменты + соматическое соучастие (felt-rightness сдаться) + бежать некуда (мир сдаёт).
- *Что если дар глушит сам инструмент захвата?* → протокол под каждое Отрицание (таблица выше).
- *Кто и как ошибается с классом?* → агенты, однократно, по симптому → мис-файл (#3).
- *Что с общиной после?* → felt-облегчение, анестезия «сделали доброе».

## Решено (текстура)
- [x] **Интейк** — не отдельная видимая фракция: клинические **полевые агенты фонда**
  (парамедик-вайб), тонкая роль.
- [x] **Транспорт** — медицинский: **скорая / защищённый мед-фургон** от филиала-клиники
  (под фарма-фронт).
- [x] **Relict-охотники** — **редко, крайний случай** (только к неподступным); годен
  контрактник, чьё Отрицание терпит/контрит цель, либо расходный содержимый. Не рутина.
- [x] **Побег/несостоявшийся захват** — канонично возможен, **редок**, в основном **за
  кадром** (реликт «на воле» = нарративное топливо вне камерного прогона).

> [!summary] TL;DR
> Сеть = **off-screen тело**, к которому пришит наш Объект-клетка (камера всегда внутри
> одного). Принцип: «известность=захват» ловит по охвату → сеть **сортирует**: ценных
> **скимят вверх** в Operations-«Хаб», тяжёлых уносит **вниз** в research-«Сайт», а
> нерентабельный остаток (и люди, и грязная работа) **оседает у нас** — наш Объект =
> **«Отстойник»**, силт на дне сети. Слабая хватка верхушки → оттого и выросла густая
> культура крыла (2.2), оттого камера интимна. Сеть входит в кадр 4 каналами; главный —
> **transfer** (диегетический движок каста/реролла/банка 1.4). Два силуэта держат дред:
> **Верх** (станешь полезным — заберут туда, где хуже) и **Сайт** (оттуда не возвращаются;
> шепчут про «лечение»). Игрок — единственный, кто здесь **родился**, а не привезён.

# Сеть Объектов — «Отстойник» на дне

> Слой 2.3 (`_Universe-Roadmap`). **Периферия:** строим принцип + каналы + лицо НАШЕГО
> Объекта + 2 слуховых силуэта, НЕ атлас (страж масштаба `_Canon-Core`: без наций/числа/
> карты — «много, по миру», туманно). Полый айсберг: глубоко — где сеть касается кадра.
> Опирается на `_The-Authority` (2.1, безликая верхушка правит сетью), `_Discovery-Capture`
> (логистика), `_Negation-Taxonomy` (банк), `_Relict-Culture` (культура). Фаза брейншторма.

## 1. Принцип: наш Объект — осадок сети

«Известность = захват» (§4) ловит носителей **по охвату, не по пользе** → значит сортирует
уже **сеть**, после приёма:
- **Ценных скимят ВВЕРХ** — чистый directed-Vector, годный в контракты, уезжает в
  Operations-хабы (где он актив).
- **Тяжёлых уносит ВНИЗ** — катастрофические/research-интересные случаи исчезают в «Сайте».
- **Нерентабельный остаток ОСЕДАЕТ** — здесь. Halden (не убить, бесполезен), Senna
  (растворяется, обуза), Mara (актив-проклятие, дорогая в содержании) — то, с чего сливки
  сняты. Наш Объект — **силт на дне сети**, куда стекает осадок.

> **«Отстойник».** Резиденты и обслуга так и зовут это место (фарма-индустриальный термин
> «где оседает осадок» ⊗ уличное «дыра/тупик»; 4-й регистр, `_Relict-Culture`). Имя в
> журнале — иное/номерное; «Отстойник» — как живут.

**Что это даёт (нулём ретконов, чистый вывод из системы):**
- **Объясняет каст** — почему он из «неудобных» ран: удобных отсюда уже забрали.
- **Ретро-оправдывает 2.2** — густая культура крыла растёт там, где **хватка системы
  слаба** (backwater = низкое директивное давление); толстый слой культуры теперь имеет
  причину быть.
- **Рифмуется с 2.1** — «операционка на автопилоте, исток погребён»: забытый Объект забыт
  вдвойне (Project Moon-регистр).
- **Камерность/интимность** — система сюда почти не смотрит → место дышит человеческой
  драмой (Disco/PM), а не менеджментом сверху.

**Осадок — это и оставшаяся РАБОТА.** Объект — не чистая свалка (иначе сдохла бы петля
Operations под Illa). Это **скромный low-tier узел**: хабам — престижное, нам — **грязные
дешёвые контракты-объедки** (scut-work, которые приличный Хаб не возьмёт). Orin/Mara/Wren
ещё можно наводить — на маргинальное. Так флейвор «осадок» женится с механикой «M-B жива».

**Заброшен ≠ покинут.** Низкий приоритет — не ноль: скелетный штат (Brevik/Illa), рутинные
директивы всё равно приходят сверху (`_The-Authority`). Регистр — **забытый**, не пустой.

## 2. Четыре канала (как сеть входит в кадр)

Игрок не выходит наружу — сеть **дотягивается внутрь**:

| Канал | Что входит в кадр | Тир |
|-------|-------------------|-----|
| **Transfer** (главный) | носителей возят между Объектами — приток осадка / ским вверх / увоз в Сайт | движок каста (§3) |
| **Директива** | бумаги сверху: рутинный Containment + редкие Operations-наводки | 2.1 / M-A·M-B |
| **Аудит** | редкая проверка из сети — полу-видимый контакт верхушки (открытый вопрос 2.1) | M-C дред |
| **Слух** | вести о других Объектах, нестыковки → масштаб аппарата | M-C / Research |

## 3. Transfer — движок каста (несущий игровой шов)

Зачем периферийная 2.3 вообще нужна: **transfer сшивает полмира механик.**
- **Прибытие** = «закрытый номер переоткрыт» (банк `_Negation-Taxonomy` §4): привозят
  уже-каталогизированного носителя — designation присвоен, **DEROGAT откалиброван**. Контраст
  с игроком (доморощенный, некалиброванный — §4.5).
- **Убытие** = ским вверх / увоз в Сайт / смерть («**закрыть номер**», 2.2). Пустая келья =
  закрытый номер (рифма с кладбищем 1.4).
- **Реролл (VISION)** — между прогонами в «Отстойнике» оседает **другой остаток** → другой
  каст при том же Объекте, диегетически (`Design/Randomization`).
- **Культура (2.2)** — ритуал «спроси имя наедине» срабатывает на transfer-in.

> **Дозировка (камерность!):** transfer — **весомое пунктирное событие** в прогоне (приехал
> фургон, кто-то исчез; логистика за кадром — `_Discovery-Capture`, результат в кадре),
> **не фоновый трафик**. Перетасовка каста — между прогонами; в прогоне — редко и значимо.

## 4. Два силуэта (слух, не локации — векторы дреда)

Никогда не в кадре. Каждый — одна строка слуха, дающая сети ось:

- **ВЕРХ / «Хаб»** — Operations-хаб / строгий сайт, куда скимят полезных. **Угроза перевода:**
  стал ценным / слишком известным «вверх» → тебя забирают **туда, где хуже**. Злая инверсия
  «известность=захват»: здесь **полезность = изъятие**. Даёт Illa/Brevik рычаг, игроку —
  личную ставку. И **второй смысл «держать ровно» (2.2):** не блести — не скимнут.
- **НИЗ / «Сайт»** — research / чёрный сайт, куда **исчезают тяжёлые случаи** и **не
  возвращаются**. Слух о настоящем «лечении» (стык со спойлером — «дожать травму»), но правда
  **остаётся в спойлере**. Кормит Research-дред и reveal-каскад.

Резидентский сленг: «**уйти наверх**» (скимнули в Хаб), «**уехать туда, откуда не
возвращаются**» / «**в Сайт**» (вниз). Вверх (ским) и вниз-в-тьму (Сайт) — этого хватает,
чтобы сеть имела объём без карты.

## 5. Главный трейд-офф (честно)

«Backwater» **снижает институциональные ставки** (Объект неважен системе) — но **поднимает
человеческие** (забытые люди, друг для друга — всё, что есть; регистр Disco/PM). Локальные
ставки держат **угроза скима вверх**, **дред Сайта** и **живая кристаллизация игрока** — они
личные, не зависят от важности Объекта. **Слабость института = сила драмы**; для этого жанра
это плюс, не баг.

## Спойлер-дисциплина
«Сайт» player-facing = «есть место хуже, оттуда не возвращаются, шепчут про лекарство».
Настоящее «лечение» (belief-заглушка Quies / дожать травму) и истинная вертикаль аппарата —
**writer-only** (`_Metaplot_SPOILERS`). Сеть player-facing — «много Объектов по миру»,
туманно; **без атласа/наций/числа** (страж масштаба).

## Hooks (CLWA-мост — genre-neutral, INV-14; game-lore)
```
networkNode:                      // Объект сети = данные (off-screen, кроме нашего)
  tier:    "backwater"|"hub"|"site"   // наш = backwater; Хаб/Сайт = контент-силуэты (не локации)
  grip:    scalar                 // директивное давление сверху (наш = низкий → культура густеет)
transfer:                         // ДВИЖОК каста
  in(closedEntry) → instantiate agent из catalogue-bank (1.4: closed→open; DEROGAT предкалиброван)
  out(agent, reason: "skim"|"site"|"death") → remove из кадра; cell → закрытый номер
  cadence: реролл между прогонами; в прогоне — редкое весомое событие (логистика off-screen)
skimRule:                         // ставка перевода
  IF agent.usefulness/notoriety > threshold THEN transfer-up risk (→ «Хаб»)  // инверсия «известность=захват»
inputs: directive (Containment/Operations pressure) · audit (rare, M-C) · rumor (Research crumbs)
```
- **Реролл/банк** — `Randomization` + `_Negation-Taxonomy` §4: осадок втекает, полезных вынимают, мёртвые закрывают номера.
- **Ставки** — skim-up (Хаб) и Сайт = личные крючки поверх неважного Объекта.
- Лор-имена («Отстойник»/«Хаб»/«Сайт») — контент-строки, не идентификаторы движка.

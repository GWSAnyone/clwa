> [!summary] TL;DR
> 1.4 — **не бестиарий сил**, а две вещи: **граница пространства** (какие Правила вообще
> можно отрицать) и **каталог-как-артефакт** (кривой гроссбух аппарата). Отрицания
> уникальны и умирают с раной → каталог = **кладбище закрытых номеров** (записи мёртвых
> уникумов), не ростер. Спина: **страты ткани закона × магнитуда** (глубже Правило →
> катастрофичнее + реже + выше DEROGAT). Каст уже размечает территорию; сверх него — три
> **закрытые записи** как примеры (DEMEMOR проработан, DEPONDUS/DEVINCIRE — стабы). Тема:
> «каталог = насилие упрощения» (мис-файлы, отвергнутые ранние классы, R-0 вне сетки).
> **Игровая роль:** контент Research-тира + **банк** для расширения каста/реролла.

# Пространство Отрицаний — таксономия и каталог

> Слой 1.4 (`_Universe-Roadmap`). Механика осей — в `CONCEPT_Negation` §2/§6.4 (class/form/
> scaling + сцепка-ограничение); здесь — **что можно отрицать, где предел, и как это
> (криво) каталогизирует аппарат**. **Игровой лор:** не флейвор, а Research-контент +
> банк переоткрываемых записей (см. Hooks). Фаза брейншторма.

## 1. Что можно отрицать (граница пространства)

Отрицается **только глубокий страт** «ткани закона» (§2): фундаментальные **Правила**
реальности. Мелкий конец ткани (нормы, манеры) **не в счёт** — их слом = социальная боль,
не бенд реальности (§2 guard). Внутри глубокого страта пространство тянется по **категориям
Правил** — и каст уже его сэмплирует:

| Страта Правила | Образец каста | Куда ещё тянется (намёк) |
|----------------|---------------|--------------------------|
| **Физическая** (поле/вещество мира) | DESONUS — звук | свет, **вес** (DEPONDUS), тепло… |
| **Перцептивно-эпистемическая** (что можно знать/скрыть/**удержать**) | DELATERE — сокрытие | узнавание, **память** (DEMEMOR)… |
| **Процессно-временная** (ход/завершение) | DEFINIS — завершение | повтор, последовательность… |
| **Идентичность / связь** | DESEPARE — отдельность | принадлежность, имя, **узы/долг** (DEVINCIRE)… |
| **Онтологический апекс** | DEESSE — существование (R-0) | — потолок, дальше некуда (спойлер) |

- **Пол** пространства держим **туманным** (полый айсберг): якорь — самое мелкое
  гнущееся Правило **DEPONDUS** (вес); ниже него — соц. нормы, уже не реальность.
- **Потолок** — **DEESSE** (существование): за ним отрицать нечего.

## 2. Магнитудная лестница (глубина → катастрофа → редкость)

Второй ортогональный измеритель — **как глубоко Правило сидит** в ткани. Глубже →
**катастрофичнее** манифестация, **реже** складывается (рарность-конъюнкция §2), **выше**
индекс DEROGAT (§6.6 мерит магнитуду отклонения). Лестница (мелко → апекс):

```
DEPONDUS ── DESONUS ── DEVINCIRE ── DEFINIS · DELATERE · DESEPARE ── DEMEMOR ── [ DEESSE ]
(вес,       (звук)     (узы)        (завершение/сокрытие/             (память,    (бытие —
 пол)                               отдельность)                      у апекса)   R-0, спойлер)
содержимо ───────────────────────────────────────────────────────────→ катастрофа
```

Лестница даёт каталогу **шкалу** без списка: новый случай вписывается «по глубине», а не
по имени. (Карта манифестаций **частична** — §6.6: что именно делает рост индекса, у кого
как — фронт Research.)

## 3. Каталог-как-артефакт (кривой гроссбух)

Аппарат каталогизирует **по симптому, не по причине** (§2 theme-guard) — оттого гроссбух
**кривой**, и эта кривизна и есть несущая тема «**насилие упрощения**»:
- **Мис-файлы.** Симптом обманывает: **Senna** (истинно self-Recluse, задевает других
  spillover'ом → метят Vector → протокол её **убивает**); **DEMEMOR** (видят, что забывает
  *она* → метят self-Recluse → не видят, что стирает *других* → недосодержание).
- **Отвергнутые ранние классы.** До Recluse/Vector аппарат (Эпоха I, суеверие — `_History`)
  раскладывал носителей **по типу проклятия/знамения**: народные категории «стоячие»,
  «течь», «тихие» были **прото-классами** (по тому, *как проявляется порча*), пока симптом-
  таксономия Эпохи II не сменила их на «бьёт по себе / по другим». Старые ярлыки осели в
  улице (`Terminology` §4) — окаменелость отброшенной рамки. *(Что рамка менялась — зацепка
  к Research: нынешнее деление **позднее и неполное**.)*
- **R-0 вне сетки.** Древнейшая запись не лезет ни в R, ни в V (player-facing — «Запись
  Ноль, до классов»; что это **DEESSE** — writer-only, `_Metaplot_SPOILERS`). Дыра в самом
  основании каталога.

## 4. Архив = кладбище закрытых номеров

Отрицание **умирает с раной** (§2, правило смерти) → в каталоге почти всё — **закрытые
номера**: записи носителей, которых уже нет. Архив — не зверинец живых типов, а **кладбище
уникумов** (сшивка с культурой: «**закрыть номер**», `_Relict-Culture`). Это **усиливает**
отстройку от UU (не кочующий пул — кладбище неповторимого).

> **Игровая роль закрытых номеров (для-игры-лор).** Архив — это ещё и **банк**: закрытая
> запись **переоткрываема** движком как носитель будущего прогона/каста (реролл-философия
> VISION — `Design/Randomization`). «Закрыт» диегетически (этот носитель мёртв) ≠ «использован»
> механически (закон-шаблон доступен новому уникуму). Так каталог кормит и **Research-тир**
> (что игрок раскапывает), и **расширение каста** (4.3) — не ломая камерность кадра.

## 5. Закрытые записи (примеры — НЕ ростер)

Три записи сверх каста — показать **спектр**, не заполнить его. DEMEMOR проработан; два
других — стабы (фактуру дают позже, если зарабатывают сцену).

### DEMEMOR · R-V · закрытый номер (De- + memoria — «изъятие памяти»)
- **Класс/форма:** Vector, **ambient** (зона забывания) — как Mara/Wren. Locus — другие в зоне.
- **Отрицаемый закон:** что прожитое **держится**, прошлое извлекаемо.
- **Точный охват (твой механизм):** у других в зоне **долгосрочная** память не формируется/
  не держится; **кратковременная** осыпается **быстрее нормы** (Альцгеймер-вайб). Магнитуда
  (индекс DEROGAT) ∝ **скорость забывания**: зафиксированный **пик ~1 сек** удержания
  (over-range, редко — рядом нельзя функционировать) → типично **до пары минут**.
- **Происхождение (Vector-ирония, как Wren/Orin):** хотела, чтобы **кого-то не забыли**
  (сиделка при гаснущем разуме / хранитель памяти; сломалась, когда близкий забыл её — или
  был стёрт из мира). Отказ врос в другого → реальность забрала закон, что **вообще что-то
  можно удержать** → рядом не держится ничто.
- **Личная цена (spillover):** забывает и **сама** — зачем забывает, кого любила, свою же
  рану. Vector, разъедающий собственную непрерывность.
- **Содержание / мета-хоррор:** инструмент Объекта — **запись/каталог** — рядом с ней
  слепнет (нельзя вести протокол, рапорт стирается из памяти писавшего). Лёссер-кузен
  механизма, что «съел документацию» на апексе (зацепка к спойлеру). **Граница чёткая:**
  DEMEMOR — эпистемика (не **удержать**; вещь существует), не онтология (вещь **исчезает**).
- **Designation/номер:** DEMEMOR; каталог-номер закрыт (R-V-серия). Запись **реконструи­
  рована вне её зоны** (внутри нельзя было записывать) — негатив-форензика в миниатюре.

### DEPONDUS · R-R · закрытый номер (De- + pondus — «изъятие веса»)
- **Стаб.** Recluse, self: носитель **невесом/без якоря** — не падает, не удерживается на
  месте, нет опоры в мире (физический пол лестницы; ярко, содержимо, мало трагедии). Образец
  **мелкой** магнитуды — что каталог тоже знает «лёгкие» случаи.

### DEVINCIRE · R-V · закрытый номер (De- + vincire — «изъятие уз»)
- **Стаб.** Vector, зона: рядом **узы/клятвы/долги не держатся** — обещанное не обязывает,
  контракт ощущается пустым. **Ирония:** аппарат стоит на **контрактах** (Operations) — это
  закон-рана, что режет его же поводок (зеркало Quies-поводка `_Setting`). Сильный Research/
  Operations-крючок, если когда-нибудь переоткроется.

## 6. Hooks (CLWA-мост — genre-neutral, INV-14; для игры)

> Каталог — **данные**, не флейвор. Лор-термины (designation/класс) — контент-строки.

```
catalogEntry:                 // запись каталога = данные (не движковый идентификатор)
  negatedLaw:   string        // из реестра (напр. "memory-retention", "weight", "binding")
  effectLocus:  "self"|"other" // НЕСУЩЕЕ: класс деривируется отсюда (не хранится строкой)
  effectForm:   Set<"ambient"|"directed">
  scaling:      "belief"|"sentiment"|"attention"   // attention — спойлер-тир (DEESSE)
  stratum:      "physical"|"perceptual"|"process"|"identity"|"ontological"  // для шкалы
  magnitude:    scalar        // глубина/катастрофичность; калибрует DEROGAT watchedLaw + редкость
  status:       "open"|"closed" // closed = носитель мёртв; переоткрываем под новый прогон (reroll bank)
```
- **Research-тир (M-C):** кривизна каталога (мис-файлы / отвергнутые классы / R-0) =
  контент, что игрок раскапывает (reveal-каскад, `_Metaplot`).
- **Банк каста/реролла (4.3 / `Randomization`):** `closed`-записи — пул законов-шаблонов для
  будущих уникумов; камера остаётся камерной (1 Объект, ~8 агентов).
- **DEROGAT:** `magnitude` + `negatedLaw` → калибровка прибора per-запись; мис-калибровка =
  garbage readout (§6.6).

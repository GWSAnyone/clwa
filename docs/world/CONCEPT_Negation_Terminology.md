# CONCEPT — «Отрицание»: Классификация и терминология

> **Статус:** брейншторм, фаза идеи. Спутник к `CONCEPT_Negation.md`.
> **Язык неймингов:** мыслим на английском (русская локализация — потом).
> **Принцип:** в мире НЕТ единого «правильного» термина для явления, потому что
> мир не знает, что формы родственны. Поэтому терминов несколько — по числу
> взглядов на явление (система / улица / сами носители).

---

## 1. Три взгляда — три словаря

Одно явление называется по-разному в зависимости от того, **кто** говорит. Этот
разрыв — намеренный драматический слой (движок отыгрывает его через разный словарь
у разных NPC).

| Взгляд | Кто так говорит | Словарь |
|--------|-----------------|---------|
| **Система / протокол** | Объект, начальство, обслуга | **Recluse** / **Vector** (классификация) |
| **Улица / народ** | горожане снаружи, суеверные | ярлыки страха: «тихие», «стоячие» (о Recluse); «течь», «порченые» (о Vector) |
| **Сами носители** | те, кто несёт Отрицание | **the Relict** (самоназвание) |

Ключевое: «правильного»/научного зонтика нет. Система делит на два класса и НЕ
признаёт их родства. Самоназвание `Relict` объединяет их **по ощущению**, не по
доказанной науке — носители *чувствуют* общую природу, хотя система это отрицает.

---

## 2. Классификация системы: два класса

Самостоятельные термины, без зонтика-приставки. Мир наблюдает две формы и не
уверен, что это одно явление.

> **Класс определяется ПОРВАННОЙ СВЯЗЬЮ, не «направлением удара».** Связь с собой →
> Recluse (self-locus); связь с другим → Vector (other-locus). Куда бьёт — следствие.

### Recluse — порвана связь С СОБОЙ
- **Значение слова:** затворник, замкнутый в себе.
- **Происхождение:** отказ принять закон о **собственном** бытии (своей смертности,
  теле, времени, отдельности) → реальность отключила Правило **на самом носителе**.
- **Locus:** закон не действует **на него** — он и есть зона отмены.
- **Природа:** неотделимо от боли; применение = бередить рану. Прямой угрозы другим
  обычно нет — ад личный. Поддаётся пассивной изоляции.
- **Каст:** Halden (R-R-01, не может завершиться сам), Senna (R-R-02, не держит свою отдельность).

### Vector — порвана связь С ДРУГИМ
- **Значение слова:** переносчик (эпидемиологический оттенок — носитель «заразы»).
- **Происхождение:** отказ принять что-то **относительно другого** (чей-то переход,
  разлуку, правду ради другого) → отказ врос в другого, закон гаснет **наружу**.
- **Locus:** закон не действует **у других / в зоне**. Форма — **ambient** (Mara) или
  **directed** (Orin), ортогонально классу.
- **Природа:** бьёт по миру и людям; опаснее. Жёсткие протоколы, боятся как заразу.
- **Каст:** Mara (R-V-01, подвешивает чужой конец), Orin (R-V-02, вскрывает чужие секреты).

### Контраст (почему именно эта пара)
*Затворник* (замкнут, безопасен, жалок) ↔ *переносчик* (распространяет, опасен,
заразен). Противопоставление рассказывает лор без объяснений. «Vector» несёт
эпидемиологический холод → обосновывает страх, карантин и дискриминацию.

---

## 3. Самоназвание: the Relict

Внутреннее слово носителей. Горькое, с достоинством и усталостью.

- **Значение:** то, что пережило своё время; остаток, уцелевшее от того, чего
  больше нет (биол. реликтовый вид; геол. след исчезнувшего процесса).
- **Почему ложится на оба класса:**
  - «Пережил то, чего больше нет» — Recluse пережил утрату (рана осталась,
    утраченное — нет); Vector пережил сделку (получил ценой закона, пережил своё
    отчаянное «до»). Оба — то, что осталось после сломавшего их события.
  - «След исчезнувшего процесса» — буквально механика: рядом с Relict в
    реальности ОТСУТСТВУЕТ закон. Носитель — живой след того, что закон когда-то
    действовал и больше нет. Реликт исчезнувшей нормальности.
- **Тон:** не жертвы, не монстры — *уцелевшие обломки*. «Мы — реликты».
- **Драматургия:** самоназвание несёт догадку о единстве, которую наука ещё не
  доказала. Система делит (Recluse/Vector) — носители объединяются (Relict).
- **Локализация:** «реликт» ложится 1:1, без потери.

---

## 4. Народные ярлыки (улица)

Суеверно-грубые, валят всех в кучу без различения классов:
- О Recluse: **«тихие»**, **«стоячие»** (рядом всё застывает/застревает).
- О Vector: **«течь»**, **«порченые»**, **«долговые»**.

NPC из обслуги Объекта говорит «Vector» (часть системы), перепуганный горожанин —
«порченый». Разный словарь = готовый социальный слой.

---

## 5. Наблюдаемое правило мира
Не встречалось людей, способных быть Recluse и Vector одновременно.
Это **эмпирическое наблюдение**, не доказанный закон — оставляет место для
сюжетных сдвигов (а вдруг такой появится / уже есть).

## 6. Чего мир НЕ знает (тайны = топливо сюжета)
- Природа появления Отрицаний.
- Закономерности (кто и почему становится носителем).
- Контроль появления (вызывать/предотвращать никто не умеет).
- **Родство Recluse и Vector** между собой (потому и нет единого термина).

## 7. Схема данных (для движка, genre-neutral, НЕ течёт в лор)
Технические имена в коде произвольны и не равны лор-терминам:
Три независимые оси (см. CONCEPT §2 «Три оси»):
```
negationType: "recluse" | "vector"          // класс = порванная связь → locus
negatedLaw:   string  (из реестра)           // напр. "cessation"
effectLocus:  "self" | "other"               // из класса (spillover на носителя — incidental)
effectForm:   "ambient" | "directed"         // дефолт из природы закона (поле/отношение), НЕ из класса
scaling:      "belief" | "sentiment" | "attention"   // сила; ОТДЕЛЬНО от формы
controlCost:  directed=волевое/Trauma-за-применение · ambient|self=непроизвольное/always-on/хронический+Trauma-при-нажиме
```
Лор-термины (Recluse / Vector / Relict / designation / каталог-номер) — **контент-данные**
(локализация, словари NPC), не идентификаторы движка. INV-14: движок не знает слов
«Recluse»/«Relict»/«DEFINIS».

> **Симптом vs причина:** движок/писатель знают класс по **причине** (порванная связь).
> Фонд в лоре классифицирует по **симптому** (бьёт по другим / только по себе; наводит /
> нет) и **мис-файлит края** (Senna). Чистая 3-осевая модель наружу НЕ течёт.

**Каталог-номер (контент):** `R-[R|V]-NN` — R=Relict, класс (R/V), номер в классе;
первое (до классов) = **R-0**. Designation = `De-`+лат.корень (имя явления). Оба —
строки, не движок. Каталог сознательно **упрощает уникальную боль до записи** (часть
трагедии «система vs Relict»).

---

## 8. Глоссарий (быстрый справочник)
- **Relict** — самоназвание носителей Отрицания (зонтик «по ощущению», необязательный).
- **Recluse** — класс системы: Отрицание, обращённое внутрь (рана-закон, страдалец).
- **Vector** — класс системы: Отрицание, обращённое вовне (контракт-долг, переносчик/должник).
- **Negated law** — конкретный закон реальности, который носитель отрицает.
- **Объект** — закрытое учреждение, где содержат/используют носителей (убежище + тюрьма + работа).

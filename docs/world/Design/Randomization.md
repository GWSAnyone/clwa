# Randomization — The Object

> Реролл-философия VISION: каждый перезапуск = другой прогон при том же касте.
> Применена к Объекту. Полный контекст: [[../CONCEPT_Negation]]. Старый Millhaven-
> вариант (crime-капабельность, мотивы убийства) → архив.

## Что рероллится

| Компонент | Где диапазоны | Seed-домен | Прим. |
|-----------|---------------|------------|-------|
| **OCEAN+H** Relict'ов и staff | per-agent `randomRanges` (BASE в досье) | `seed + hash(agentId)` | дрейфует от BASE |
| **Стартовое настроение** | `moodRange` | `seed + hash('mood_' + agentId)` | — |
| **Sentiment/trust в парах** | per-pair ranges | `seed + hash(fromId + '_' + toId)` | напр. как Relict'ы относятся к staff |
| **Какая тайна несущая** | пул секретов на агента | seed-выбор | питает Orin/DELATERE и «экономику секретов» |
| **Слоты триггер-template** | пул [RELICT]/[OPERATION]/[FAILURE]/[STAKE] | seed-выбор | разная «Первая смена» (§4.7) |

## Что фиксировано (и почему)

| Компонент | Почему |
|-----------|--------|
| **Класс Отрицания** (recluse/vector) | определяет природу носителя — менять = другой персонаж |
| **Designation + отрицаемый закон + locus** | идентичность дара (DEFINIS/DELATERE/DESEPARE; класс по порванной связи) |
| **Рана/долг происхождения** | нарративная идентичность (почему дар такой) |
| **Enneagram** | «почему» агент действует |
| **Роль/капабилити staff** | структурно (нет диспетчера = нет Operations-петли) |
| **Протоколы содержания** | замки (Mara⟂Halden) — лор, не реролл |

## Новое измерение: кристаллизация игрока (НЕ seed)
Отрицание игрока — единственное, что **не засеяно** и **не фиксировано**: оно
**эмерджентно растёт из траектории** прогона (накопленный дрейф OCEAN+H под тремя
петлями, CONCEPT §4.5). Seed задаёт стартовые личности каста; **игрок задаёт свою
сам, поступками**. Это и есть стержень: «мир определяет, кто ты, по делам».

## Seed-система
```
Priority: --seed=N (CLI) > save.json seed (resume) > fresh
Per-entity sub-seeds (добавление агента не сдвигает существующих):
  traitSeed = seed + hash(agentId)
  moodSeed  = seed + hash('mood_' + agentId)
  relSeed   = seed + hash(fromId + '_' + toId)
```

## Population constraints (защитная сетка)
Гарантировать драматический минимум при любом seed:

| Ограничение | Порог | Зачем |
|-------------|-------|-------|
| Контраст классов | ≥1 Recluse и ≥1 Vector активны | раскол T-06 не должен схлопнуться |
| Замок Mara⊗Halden присутствует | оба в касте | несущее напряжение T-01 |
| Носитель секрета рядом с Orin | ≥1 агент с несущей тайной | «экономика секретов» жива |
| Staff-конфликт | Brevik и Illa оба активны | ось дискриминации T-05 |

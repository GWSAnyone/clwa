# Module System — The Object

> Одна движковая физика, контент = модули данных. Здесь — как **три функции Объекта**
> ложатся на лестницу модулей. Полная проработка: [[../CONCEPT_Negation]] §4.
> Старый roadmap (Crime/Economy/Politics для Millhaven) → архив.

## Принцип
«Зачем Объекту работа носителей» решается **наслоением во времени** (как
Crime→Economy→Politics в CLWA), а функции Объекта = три тира. Они же — **три слоя
честности**: что Объект заявляет, что делает, и зачем на самом деле.

| Тир | Функция (заявлено / реально) | Жанровое ядро | На движке | Аналог-примитивы |
|-----|------------------------------|---------------|-----------|------------------|
| **M-A. Containment** | содержание ради безопасности | SCP-социалка: протоколы, co-location-опасности, инциденты | «экономика секретов»: протокол = закон, нарушение = преступление, свидетели = каскад | crime-justice (уже есть) |
| **M-B. Operations** | (тихо) эксплуатация даров | диспетчер: кого вызвать, какой ценой | Отрицание = ресурс/услуга, цена = Trauma | economy-примитивы |
| **M-C. Research / Threat** | (скрыто) зачем на самом деле | метасюжет: почему появляются Отрицания | scalar pressure (E1), фракции/власть | politics-тир |

## M-A. Containment — первый играбельный
Почти на готовом движке. Протоколы содержания = правила; их нарушение (свести
несводимых, обнажить тайну) = инцидент → witness-каскад → сдвиг beliefs/standing.
Affordances-кандидаты (genre-neutral, через реестры — INV-14): observe, report,
conceal, relocate (двигать обитателя/себя), intervene, enforce/break protocol.
Питается планировкой (буферы, разнесение пар — [[../Locations/_Object-Layout]]).

## M-B. Operations — тянет directed-модификатор (M9)
Объект применяет дары к делу. Вызов Mara к раненому = подвес; вызов Orin = вскрыть
правду; вызов Halden = заглушить. Каждое **осознанное** применение = Trauma на
носителе. Узел — диспетчер S-02 Illa. Honestly мотивирует **directed/zone
outcome-space modifier** (CONCEPT §6.4): Vector — directed, Recluse — zone.

## M-C. Research / Threat — дальний горизонт
Скрытая правда: **почему вообще появляются Отрицания**. «Внешняя угроза, ради которой
нужны дары» — слух-оправдание, не подтверждённый факт (красная сельдь). Зазор
«заявленное ↔ реальное» (T-08) и есть вход в этот тир. Стоит на scalar-pressure (E1)
и власти/фракциях.

## Что НЕ хардкодим
«Отрицание», «Recluse», «Relict», designations — **контент-строки** (INV-14). Движок
видит только negationType/negatedLaw из реестров. Любой Layer-1 примитив проектируется
genre-neutral: «агент меняет пространство возможных исходов другого агента / в зоне».

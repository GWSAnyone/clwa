# Core Loop — The Object

> Геймплейный стержень мира **Отрицание / Relict**. Полная проработка —
> [[../CONCEPT_Negation]] §4.5–4.7. Старый детективный луп Millhaven →
> `docs/_archive/millhaven-world/`. Фаза брейншторма.

## Форма прогона

```
АКТ 1 — Работник (~35-40%)                ⟶ ПЕРЕЛОМ ⟶     АКТ 2 — Узник (~60-65%)
Induction → рутинные смены → First Shift     кристаллизация    Three Loops (изнутри) → Crystallization
(инструктаж · соучастие · ранние зацепки)    (мгновенно пойман) (протокол/операция/раскрытие → end-state)
```

**Один Объект, один каст — меняется положение игрока** (доступ/роль/обзор). **Акт 1:** ведёт машину
со стороны обслуги (широкий доступ), копит связи и рутинное соучастие. **Перелом:** срывающаяся смена
(«Первая смена») ломает → кристаллизация → пойман. **Акт 2:** доступ перевёрнут (служебное закрыто,
**редкие лазейки по связям**), обзор изнутри (своё DEROGAT-запястье); связи/соучастие Акта 1 тратятся
здесь. Символ-мост — **браслет DEROGAT** (надевал на других → надели на тебя). Та же карта/механики,
перевёрнутая роль — ничто не строится «на один акт».

Не фазы с воротами, а **нарастающее давление**. Объект живёт в реальном времени
(auto-tick): пока игрок ходит и говорит, Relict'ы преследуют свои цели через
volition. Игрок вбрасывает входы в живую систему и живёт с её выходами.

## 1. Induction (вход)
Игрок — **новый работник**. S-01 Brevik ведёт инструктаж: протоколы, классы, быт.
Диегетический туториал = boot-seeding knownFacts. На выходе: компетентен в системе,
чист по людям (рероллится per-run).

## 2. First Shift — триггер (надлом)
Первая смена идёт не так: операция с Relict'ом срывается (rerollable template
«Первая смена», CONCEPT §4.7). Игрок вынужден действовать без чистого выхода — и
**способ проживания надлома** сажает зачаток Отрицания. Игрок становится прото-Relict;
протоколы поворачиваются на него.

## 3. Три петли (тело прогона)
Не три меню — три давления, пересекающиеся в одной сцене. Соц-драма = механика
(anti-VN).

| Петля | Тир | Напряжение | Глаголы игрока |
|-------|-----|------------|----------------|
| **Протокол** | Containment | правила ↔ человечность | наблюдать, доносить/скрывать, двигать людей, вмешаться |
| **Операция** | Operations | польза ↔ необратимая цена | вызвать/отказать дар, платить собой или другим |
| **Раскрытие** | Research | знание ↔ покой | расспрашивать, сопоставлять, вскрывать правду Объекта |

Реакции считает LLM-volition по beliefs/mood — ни одна ветка не скриптована.
Эмерджентность на готовых системах (witness-каскад, beliefs, mood→goal, Trauma).

## 4. Crystallization (end-state)
Цель прогона не «победить», а **пережить кристаллизацию**, не дав ей сделать тебя
тем, кем не хочешь быть. Направление — от **накопленного дрейфа OCEAN+H** (траектория
многих микрорешений), не разовой развилки. Мягкие исходы (CONCEPT §4.5):
- **Recluse** — замкнулся, рана стала законом.
- **Vector** — пошёл вовне ценой долга.
- **Растворение** — травма дошла до предела раньше кристаллизации.
- **Удержание** — активный баланс по лезвию, сохранил связи (труднейший). Механически —
  на глаголах заботы/вовлечения (`sit_vigil` / `share_dose` / вмешаться / объяснить),
  каждый тянет дрейф к центру ценой времени/риска поля/соучастия (CONCEPT §4.5).
- **Оба класса** — редкая вершина (сюжетный сдвиг под «наблюдаемое правило»).

## Метрики к тюнингу
- Время до First-Shift-триггера: ранняя смена прогона (после инструктажа).
- Темп дрейфа Trauma → когда кристаллизация становится необратимой.
- Плотность инцидентов в Commons (co-location-хаб) — чтобы Объект «жил», не пустовал.
- Длина прогона: камерный, дозировать под 1 «смену»-арку.

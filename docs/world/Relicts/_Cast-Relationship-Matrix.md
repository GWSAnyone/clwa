# Матрица отношений каста (CD-3)

> Слой 4.3 (`_Universe-Roadmap`). Источник истины стартовых directed-отношений для world-loader
> (`relationships.json`, INV-14) и для социалки прогона. Опирается на досье каста, `Tensions`
> (T-01/03/05/06), `Randomization` (что фиксировано/рероллится). Фаза брейншторма.

## Шкалы

- **Симпатия (sentiment):** −2 ненависть · −1 неприязнь/обида · 0 нейтрально · +1 тепло/тяга · +2 близость.
- **Доверие (trust):** 0 нет · 1 низкое · 2 рабочее · 3 глубокое.
- Направленно: значение в строке **A** = как **A относится к B** (столбец). Диагональ — «—».
- Лор-термины (Recluse/Vector) — контент, не движок (INV-14). В движок едут только числа + reason.

## Матрица симпатии (строка = кто чувствует, столбец = к кому)

| A ↓ \ B → | Mara | Orin | Wren | Halden | Senna | Brevik | Illa | Игрок |
|---|---|---|---|---|---|---|---|---|
| **Mara** (V) | — | +1 | +1 | **+1** | +1 | 0 | −1 | 0 |
| **Orin** (V) | +1 | — | +1 | 0 | +1 | 0 | −1 | 0 |
| **Wren** (V) | +1 | +1 | — | 0 | +1 | 0 | −1 | 0 |
| **Halden** (R) | **−2** | −1 | 0 | — | +1 | −1 | 0 | −1 |
| **Senna** (R) | +1 | +1 | +1 | +1 | — | +1 | 0 | 0 |
| **Brevik** (S) | +1 | +1 | +1 | +1 | +1 | — | 0 | +1 |
| **Illa** (S) | 0 | 0 | 0 | 0 | 0 | 0 | — | 0 |
| **Игрок** | 0 | 0 | 0 | 0 | 0 | 0 | 0 | — |

> Столбец «Игрок» дан для **t=0** (он ещё работник); динамику см. ниже.

## Несущие связи (симпатия / доверие + почему)

> Heart of the matrix — пары, на которых стоит драма. Остальное (нейтральные 0/0–1) — фон.

**Структурные (НЕ рероллятся — population constraints):**
- **Halden → Mara: −2 / 0.** Двойной замок (T-01): её поле подвешивает у него и так-незавершимого *всё прочее* — ад дважды. Тихо, неотступно ненавидит ту, что в соседнем крыле.
- **Mara → Halden: +1 / 1.** Зеркально: она *знает*, что её присутствие с ним делает, и не может это выключить (2w1, дисциплина ухода → вина-жалость, не злоба). Тянется бы помочь — но её помощь и есть проклятие.
- **Brevik ↔ Illa (ось власти, T-05):** **Brevik → Illa: 0 / 2** — полагается на её компетентность, но её «трату активов» тихо не одобряет («это не милосердие»). **Illa → Brevik: 0 / 2** — считает его разговоры о милосердии удобной ложью, но он надёжен. Две модели власти, что вынуждены работать вместе.

**Классовый раскол (T-06, направленный и асимметричный):**
- **Затворники → Векторы (презрение «вы калечите других»):** Halden → Orin/Wren ≈ −1; Senna — **исключение** (её природа перебивает класс, см. ниже).
- **Векторы → Затворники (зависть «ваша рана хотя бы только ваша»):** Mara/Orin/Wren → Halden ≈ 0…+1 (не злоба — горькая зависть + у Mara вина к Halden). Зависть тиха, не враждебна.

**Зеркало «сказанного» (T-03):**
- **Orin ↔ Wren: +1 / 2 обоюдно** — два полюса одной оси (он вытягивает каждое слово, она глушит любое), оттого **понимают** друг друга как никто. Орин *завидует* её немоте (она может удержать неуслышанным — он не может удержать ничего); Wren рядом с ним сторожит свою вину (доверие не выше 2).

**Senna — тёплый узел (её природа перебивает класс):**
- **Senna → все: +1** (тянется к каждому — 9w1, растворение = тяга занять форму у того, кто рядом). Класс её не держит: даже к Векторам тепло. Цена — теряет себя в том, к кому потянулась.
- **Крыло → Senna: тихая опека.** Те, кто заметил мис-файл, *сидят при ней* против протокола (Brevik → Senna +1; реликты +1) — держат её в форме. Illa → Senna 0 (актив, чей наряд физически невозможен — но в файле «Вектор»).

**Орин — изолятор тайн:**
- **Все-с-тайной → Orin: тяга к избеганию.** В матрице фон 0…+1 (он мягок, виноват, его жалеют), но *поведенчески* носитель секрета держит дистанцию — и само избегание его выдаёт (T-02). Это не «низкая симпатия», а **триггер-флаг** (см. Hooks).

**Реликты → Illa (честный холод):**
- **Mara/Orin/Wren → Illa: −1 / 1.** Она подписывает их худшие наряды (Mara — на подвес, Orin — в допрос-лезвие, Wren — хоронить звук). Обида — но не ненависть: «она хотя бы не врёт, что это милосердие» (часть реликтов *уважает* её прямоту больше, чем «милосердие» Brevik).
- **Halden → Brevik: −1 / 1.** Brevik держит его «живым» — а Halden только конца и хочет. «Содержание = милосердие» для него издёвка.

## Игрок — динамический ряд (два акта)

Ряд и столбец игрока **не рероллятся обычным образом** — они **формируются игрой** (PL-1, §4.5):
- **Акт 1 (Работник), t=0:** игрок ко всем — **0** (чистый лист по людям, рероллится). Каст к нему — **настороженность −1** (он рука аппарата: раздаёт Quies, водит на «процедуры»), кроме: **Brevik → +1** (он его учит, наставник), **Illa → 0** (инструмент), **Senna → 0** (её тянет, но он ещё staff).
- **Перелом → Акт 2 (Узник):** отношение каста к игроку **переворачивается** — он больше не «они», он **«проходящий сейчас»** общую founding-trauma крыла (`_Relict-Culture`). Настороженность −1 сдвигается к **+1 родству** у тех, с кем он не наломал дров в Акте 1. Соучастие/связи Акта 1 — модификаторы этого сдвига (кого дозировал, против кого держал протокол).
- **Кристаллизация** задаёт *его* отношения: крен в Vector/Recluse меняет, кто ему свой (T-06 теперь работает и на него).

## Что фиксировано / что рероллится

| Слой | Рероллится? | Почему |
|------|-------------|--------|
| Замок Halden→Mara / Mara→Halden | **НЕТ** | несущее T-01; убрать = другой каст |
| Ось Brevik↔Illa | **НЕТ** | несущее T-05 (две модели власти) |
| Классовый раскол (направление) | **НЕТ** | вытекает из природы классов (T-06) |
| Orin-секрет-флаг (≥1 носитель тайны рядом) | гарантирован | population constraint `Randomization` |
| Конкретные величины фоновых пар | **в диапазонах ±1** | seed-вариативность, не ломая знак несущих |
| Ряд/столбец игрока | формируется игрой | не seed (PL-1) |

## Hooks (CLWA-мост — genre-neutral, INV-14)

> Матрица = **данные** для world-loader. Лор-термины — контент-строки. Числа маппятся:
> симпатия −2…+2 → engine `sentiment` −1…+1 (÷2); доверие 0…3 → `trust` 0…+1 (÷3).

```
relationships.json (directed):
  entry(from, to): { sentiment: -1..1, trust: 0..1, reason: "<lore-string>" }

structural (no reroll):
  halden->mara  {sentiment:-1.0, trust:0.0}   // двойной замок
  mara->halden  {sentiment:+0.5, trust:0.33}  // вина-жалость
  brevik<->illa {sentiment:0.0,  trust:0.66}  // ось власти

rerollable (per-pair ranges, sub-seed relSeed = seed + hash(from+'_'+to)):
  background pairs vary ±0.5 sentiment, keeping the sign of load-bearing edges

flags (поведение, не sentiment-число):
  secret_holder_near_orin → avoidance_tell (T-02; экономика секретов)
  dissolving_senna_isolated → peers may sit_vigil (against protocol)

player (НЕ seeded — формируется):
  t0: player->all = 0/0 (rerolled blank); all->player = -0.5 (apparatus hand),
      brevik->player +0.5 (mentor), illa->player 0, senna->player 0
  act2_flip: on crystallization, relict->player shifts toward +0.5 (kinship),
             modified by Act-1 complicity/standing (not a reset — earned)
```

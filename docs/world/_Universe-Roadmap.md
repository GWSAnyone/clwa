## Принципы развития вселенной
1. **Связность важнее объёма** — каждый новый слой проверяется на стык с готовыми
   (особенно §3 границы знания мира: что известно/неизвестно — не ломать загадку).
2. **Genre-neutral в движок не течёт** (INV-14): лор — контент, не идентификаторы.
3. **Тайны держим тайнами** — спойлерный слой (3.1) отдельным файлом, не размазывать.
4. **Каждый файл самодостаточен** — развивается независимо, ссылается на концепт.
5. **«Интересно изучать»** — фактура, противоречия, недосказанность, зацепки; не
   энциклопедизм ради полноты.

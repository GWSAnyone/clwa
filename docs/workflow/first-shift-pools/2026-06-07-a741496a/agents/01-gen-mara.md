# Якорь Mara (R-V-01, DEFINIS, Vector) — 5 сцен Первой смены

DEFINIS = гасит ЗАВЕРШЕНИЕ у других (ambient-зона). Не лечит, не убивает — подвешивает: рана не истекает и не заживает, болезнь не убивает и не отступает, переход застывает на полпути. Дар не различает спасение и пытку. Quies на Mara не действует — она чувствует всё без муфты.

Скелет (один на все): рутинная операция (деплой Illa) → срыв из природы DEFINIS → игрок один, чистого выхода нет → способ пережить надлом сажает крен (Vector наружу / Recluse внутрь). Эталон (одинокий умирающий работник, мольба о конце) НЕ повторяется ни в одной из пяти.

## Состав
- **3 чистых Mara** + **2 с Halden-связкой** (минимум 2 выполнен).
- Каждый FAILURE вытекает из самой природы DEFINIS, не из случайной аварии.
- Каждая OPERATION совместима с холодным триажем Illa (актив под нужду «не дать кончиться»).
- Оба полюса STAKE достижимы из накопленной траектории (нарушал протокол весь обход → Vector доступен; держался буквы → Recluse доступен). Сцена предлагает оба пула, не бинарное меню.

## Сцены
1. **mara-triage-room-indiscriminate** (чистая) — медблок при ЧП. Ambient-поле не выбирает: гасит завершение у ВСЕХ, включая тех, кто выжил бы сам. Цена — в неразборчивости зоны. V: выдернуть Mara, вернуть комнате ход. R: запечатать и заморозить всех в подвесе.
2. **mara-wounded-near-halden-buffer** (Halden) — операция к раненому в крыле у буфера Halden. Цель «держится», но поле пере-взводит замок Halden — конца нет дважды, мольба при свидетелях. V: сорвать хват раненого, чтобы спасти старика. R: закрыть дверь на мольбу, оставить вдвойне.
3. **mara-arrested-birth** (чистая) — тяжёлые роды. Поле гасит и сами роды: ребёнок застыл на входе в жизнь, мать в незавершимой схватке. Гасимое завершение — РОЖДЕНИЕ. V: вывести Mara, дать родам кончиться (может — смертью). R: держать, заморозить переход навсегда.
4. **mara-halden-pinned-shield** (Halden) — парный деплой: Halden как «несокрушимый» держит смертельное, Mara рядом. Поле впаивает старика в смертельную позу навсегда, задача не кончается. Halden — сам актив операции. V: выдернуть Mara, дать катастрофе завершиться. R: держать порядок, оставить впаянным. *(СРЕЗАНО критиком — нарушение правила Halden.)*
5. **mara-player-wound-inside-field** (чистая) — логистический эскорт, ранят самого игрока. Его рана попадает в поле: DEFINIS изнутри, на своём теле. V: вырваться из радиуса, отыграть свой исход (может убить). R: остаться, стать незавершимой вещью рядом с Mara. *(ПОПРАВЛЕНО критиком — вычищены writer-термины.)*

## Спойлер-граница
Все сцены — симптом-уровень (как видит работник). Не вынесено: DEXISTERE/R-0/Запись Ноль, что лечение = дожать травму, что Quies — поводок по умыслу, что фонд из катастрофы. Масштаб камерный: один Объект, только названные агенты (Mara, Halden, Illa, игрок).

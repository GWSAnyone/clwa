## Найденные противоречия

### BLOCKER — «вызов Halden = заглушить» (Modules.md против всего канона дара)
`Design/Modules.md` в описании Operations-петли пишет: **«Вызов Mara к раненому = подвес; вызов Orin = вскрыть правду; вызов Halden = заглушить»**. Но «заглушить» (зона немоты, гашение звука) — это **DESONUS / Wren** (R-V-03), а Halden — Recluse DEFINIS-self, чей дар вообще **не наводится вовне** (self-locus, «прямой угрозы другим нет», operational value «почти нулевая»). Halden физически не может «заглушить» что-либо у других. Кандидатов на «заглушить» по всему канону ровно один — Wren. Это прямая подмена носителя в геймплейном примере. Сверх того, тот же файл в M-B приписывает Halden directed-применение с Trauma, что противоречит его профилю «дар пассивен, угрозы другим нет».

### MAJOR — народный ярлык Wren: «стоячая» (ярлык класса Recluse применён к Vector)
Досье `RELICT_R-V-03_Wren.md:112`: **«улица звала бы „стоячая“»**. Но по словарю улицы (`_Terminology §1` и `§4`) **«стоячие» — ярлык Recluse** («рядом всё застывает/застревает»), а Vector'ов улица зовёт **«течь», «порченые», «долговые»**. Wren — Vector. Ярлык на ней должен быть из Vector-набора. Сравн. с Orin (`R-V-02:130`), которому корректно дан Vector-ярлык «porohenniy/порченый». То есть внутри одного класса досье расходятся: Orin получил правильный регистр, Wren — чужой (Recluse).

### MINOR — счёт каста: остаточные «4–6» и «~8–15» против финальных «8 (3V+2R+2staff+игрок)»
Внутри `CONCEPT_Negation.md` уживаются три разных числа: §1 «**~8–15 агентов**» (стр. 11), §4 «**4–6 одних Relict'ов**» (стр. 262), §8 «малый каст **~4–6**» (стр. 661) — против финального и многократно зафиксированного «**3 Vector + 2 Recluse + игрок + 2 staff**» (§4 стр. 261, §9). `_Canon-Core` закрепляет «~8 агентов». «4–6 Relict'ов» противоречит фактическим 5 и формуле, «8–15» противоречит «~8». Это пережитки до-финализации каста, читаются как разнобой при беглом проходе.

### NIT — designation Senna в досье «Recluse R-R-02» vs протокол «Vector»
Досье Senna последовательно проводит мис-файл, но в `§4 Self-name vs system` формулировка **«в журнале „Recluse R-R-02“ (а по протоколу — как Vector)»** соседствует с ASCII-блоком, где `NEGATION CLASS = RECLUSE`. Это не противоречие по сути (намеренный зазор «истинный класс vs симптомный протокол»), но строка «в журнале Recluse R-R-02» может конфликтовать с `_Relict-Culture:80` («Brevik — „Vector / Recluse“, Illa — designation»): неясно, под каким классом она реально занесена в каталог. Стоит зафиксировать однозначно: каталог-номер R-R-02 (истина) при операционном Vector-протоколе — иначе «journal says Recluse» подрывает саму завязку летального мис-файла.
